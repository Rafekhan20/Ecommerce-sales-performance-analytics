# Ecommerce-sales-performance-analytics
E-Commerce Sales Performance Analytics is a data analytics project that analyzes sales data to identify sales trends, top-selling products, customer behavior, revenue, and overall business performance using Python, SQL, and Power BI.
# E-Commerce Sales Performance Analytics

## About the Project

This project analyzes e-commerce sales data to identify sales trends, customer behavior, and product performance. It uses Python, SQL, Power BI, and web technologies to present insights through an interactive dashboard.

## Technologies Used

* Python
* SQL
* Power BI
* HTML
* CSS
* JavaScript
* Pandas
* Excel

## Key Features

* Sales and revenue analysis
* Product and customer performance
* Monthly sales trends
* Interactive dashboard
* Data visualization
* Responsive web interface

## How to Run

1. Clone or download the project.
2. Open the project folder.
3. Run the Python/SQL analysis.
4. Open the HTML file in a browser.

## Results

The project provides clear insights into sales performance, top products, customer behavior, and revenue trends, helping businesses make data-driven decisions.
